# 机构 CAD 工作台

打开后直接在“建模与计算”页绘图。考题页面已移除；四杆、凸轮专用分析和自由度工具保留。

网页内可点击右上角“操作指南”或按 F1，查看分章步骤、快捷键与常见问题。目录可定位，章节可折叠；指南里的跳转按钮只打开对应面板，不会载入或修改模型。滑块面板内也可直接查看滑块操作步骤。

## 鼠标构图

1. 点“直线 L”或按 L，单击起点，再单击终点；也可按住鼠标拖出一根杆。
2. 开启端点捕捉可共用已有铰点；网格是显示辅助，5 mm 网格吸附在“更多建模参数”中独立设置。
3. 正交 F8 将下一段限制为水平或竖直；端点捕捉优先于正交。Esc 取消当前步骤。
4. Ctrl 多选、Shift 框选。选点后固定，选杆后设置尺寸、机架或滑槽。
5. 完成几何后补全驱动与约束；在“计算”里选择对象和物理量。

## 滑块与导轨按钮

先画出构件，然后按 S 或点击顶部“滑块 S”，打开独立面板。也可从左侧“支座与滑槽”进入。

1. 在列表中选择滑块，或点击“在画布选取构件”。面板展开时优先选择构件，Ctrl 可批量选择；收起后恢复原选择范围。手机选取时先收起面板，选中后自动返回；Esc 可取消选取。
2. 点击“水平 / 竖直”，或按 H / V，设置相对机架固定的导轨。输入角度后点“应用角度”，也可在角度框内按回车。
3. 已有固定导轨可用 −15° / +15° 按钮或 [ / ] 微调。旋转保留轴心，并支持批量调整。
4. 需要导轨随另一构件运动时，展开“随构件运动的导轨”，选择参考构件后应用。参考列表排除所选滑块；方向由参考杆决定，不能独立旋转。点击上方水平、竖直或应用角度，会明确改为固定导轨。
5. 可移除所选滑槽，也可用“撤销”或 Ctrl+Z 恢复。重复设置更新该滑块原有移动副，不会重复叠加约束。

S 切换面板；H / V / [ / ] 只在此面板展开且未输入文字时生效，收起后恢复原快捷键。状态框显示所选构件、导轨类型与角度。滑槽约束保留沿轴平移的自由度，模型仍需补全机构连接与驱动；不包含端部挡块或碰撞。

## 精确命令

在底部命令栏输入以下任一指令，按回车预览，再点“应用到画布”：

```text
LINE 0,0 100,0
LINE 100,0 @0,50
LINE 0,0 @100<30
```

第一条指定绝对坐标；第二条相对起点移动 (0,50) mm；第三条创建 100 mm、30° 的杆。相同坐标会共用铰点。命令栏默认追加到当前模型。

## 文字生成整机构

点击“文字建模”，选择“新建替换”，输入：

```text
创建四杆机构，曲柄30mm，连杆90mm，摇杆70mm，机架100mm，初始角60度，转速60rpm
```

或：

```text
创建曲柄滑块机构，曲柄50mm，连杆150mm，偏距0mm，滑块长30mm，初始角60度，转速60rpm
```

未填写的参数采用预览中明确列出的默认值。无法闭合、单位错误、不支持的描述会报错，不会部分应用。

这是一套本地文字规则，无需密钥；并非任意自然语言 AI。自由语义生成需要另行配置后端。文字模板的质量、转动惯量默认 0，受力计算前应填写实际参数。

## 逐行定义

```text
点 A 0,0 固定
点 B 30,40
杆 AB A B
驱动 AB 60rpm
```

对象名称使用英文字母开头、数字或下划线。支持“固定 A B”“释放 A”“滑槽 L3 水平”“滑槽 L3 90”。局部草图需自行补全机构与驱动。每次文字操作形成一个撤销步骤；预览期间画布改变后，必须重新生成草稿。

## 结果怎么看

选择点可计算位置、速度、加速度和铰链反力；选择构件可计算角运动或原动件驱动力。

当前位形：显示对象、时间、数值、单位及分量方向。扫描：显示有效/失败样本数、采样极值出现时间、曲线和逐时刻数据表。失败样本保留空值。

点击“下载文字报告”保存中文结论；点击“导出 CSV”保存完整数值。模型或计算设置变化后，旧报告会标记过期。公式与平衡方程放在“原理”中。
