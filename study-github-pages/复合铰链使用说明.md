# 普通铰点与复合铰链

## 默认规则

普通铰点最多对应一个转动副。活动点可以连接两根活动构件；固定点还包含机架，因此普通固定铰连接一根活动构件。

第三根活动构件接入普通活动点、或第二根活动构件接入普通固定点时，软件会拒绝这次连接并提示使用“复合铰链”。不会自动产生复合连接，也不会通过只显示 1 来少算实际约束。

## 使用独立工具

1. 在画布选中铰点，Ctrl 可多选。
2. 点击顶部独立的“复合铰链”。
3. 点击“启用所选复合铰链”，再继续接入构件。
4. 两个以上分开的铰点可用“合并为复合铰链”；两根交叉杆可用“交点启用复合”。
5. 画布显示复合标记和实际转动副数量；面板同时列出活动构件与机架。

启用只是允许多构件共用轴心，不会改变几何位置，也不会凭空增加一个转动副。三个构件共用活动点时，实际为两个转动副。

## 恢复普通

点击“设为普通铰链”。如果当前仍包含多个转动副，需先选择一个连接构件并点击“拆分此连接”，或删除多余连接。拆分出的新点默认为普通铰点。以上编辑均可撤销。

## 文字建模

```text
LINE 0,0 60,0
LINE 0,0 0,60
复合铰链 P1
LINE 0,0 -60,0
```

没有“复合铰链 P1”时，第三条共用 P1 的杆会被拒绝。也支持 COMPOUND P1、普通铰链 P1 和 SINGLE P1。

## 旧模型与预设

旧 JSON 和典型机构预设原来已存在的复合连接会保留，并增加明确的复合铰链标记；文件导入提示会说明转换数量。新模型明确声明为普通的点不会被自动升级。

模型文件保存每个点的 jointType（single / compound）。求解器仍按真实连接数建立约束；关闭开关不能掩盖已有的复合连接。
