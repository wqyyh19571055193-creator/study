# MECHLAB 动态机械工作台

## 视觉

使用石墨灰蓝面板、青蓝线条、橙色操作标识和细描边控件。画布保留 CAD 网格和较大的建模区域。角色、人物插画、星形装饰和原有紫粉主题已移除。

品牌标记为机构连杆矢量图。所有主题图形由本地 SVG 和 CSS 绘制，无远程字体、图片或运行库依赖。

## 动态机械示意

侧栏与文字建模窗口显示曲柄滑块示意。端点通过曲柄角度和连杆长度关系计算，连杆与滑块保持连接。绘制频率上限约 30 帧/秒，五秒演示一圈；这是界面示意速度，与模型的驱动转速不同。

示意动画独立于当前画布模型，不参与模型数据或计算结果。需要查看模型运动时，使用画布的“运动”按钮。

顶部“暂停界面动效 / 开启界面动效”控制示意动画，偏好保存在本浏览器。以下情况自动暂停：页面不可见、切换离开建模页、系统启用“减少动态效果”、手机工具抽屉与文字建模窗口都收起。

## 功能

CAD 构图、坐标命令、文字草稿确认、智能尺寸、固定支座与滑槽、独立复合铰链、中文结果与数据导出沿用当前实现。普通点仍最多一个转动副，复合连接须显式启用。

## 部署

把更新包中的文件和 assets 文件夹一起上传到现有 study-github-pages 目录。不需要删除云端旧文件才能加载新主题；新版入口已改用 mechanical.css、mechanical-ui.js 和 assets/mech-mark.svg。旧主题文件若仍留在 GitHub，可在仓库中删除。
